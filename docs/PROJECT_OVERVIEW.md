# Wealth Curator — What Was Built (Project Overview)

This document explains **what this repository implements**, how the pieces fit together, and **what was delivered** during development. For install commands, env vars, and deploy notes, see the root **`README.md`**.

---

## 1. Product summary

**Wealth Curator** is a **personal finance dashboard** (demo) that looks and behaves like a premium fintech / “editorial finance” product:

- **Net worth**, **spending**, and **savings** summaries  
- **Budget velocity** hero (modeled monthly limit vs spend, surplus, “adjust limits” CTA)  
- **Portfolio** table (sleeves / holdings with drift)  
- **Category allocation / spending** visualization (bars + lazy **Recharts** donut)  
- **Transactions** ledger with **search** (merchant, category, ticker tag, id, amount digits) and **category chips**  
- **Proactive alerts** and **documents** vault list  
- **Portfolio Insights** page section: active signal card, market sentiment gauges, performance chart, sector allocation, cash-flow intelligence cards  
- **Profile** sheet (user details, actions)  
- **Dark / light** theme persisted in **localStorage**  
- **Analytics hooks** for GA4 / GTM-style tagging (`dataLayer` + optional `gtag`)

All “AI” copy is **deterministic**: it is generated by pure functions from mock holdings, spending, and subscriptions—not from a live LLM.

## 2. Technology choices

| Layer | Choice |
|--------|--------|
| Build | **Vite 5** (ESM, fast HMR) |
| UI | **React 18** + **JS/JSX** (no TypeScript in source) |
| Cross-platform primitives | **React Native Web** — `react-native` is aliased to `react-native-web` in `vite.config.js` |
| Entry | **`AppRegistry.runApplication`** in `main.jsx` (RN-style bootstrap on web) |
| Routing | **react-router-dom** v7 — `/` loads dashboard **lazy** with `Suspense` |
| Charts | **Recharts** — imported **lazily** where heavy (spending donut, insights performance) |
| Virtual list | **@tanstack/react-virtual** for the transactions table inside a DOM scroll container |
| Icons | **lucide-react** wrapped by **`IconGlyph`** for consistent layout with RN `View` |
| Lint | **ESLint** + `eslint-plugin-react` |

## 3. Application layout (UI shell)

The main screen is **`DashboardScreen.jsx`**. It uses:

1. **`SidebarNav`** — Left rail on wide view; collapses to a **horizontal scroll** of nav pills on smaller widths. Items scroll the page to anchored sections (`section-overview`, `section-insights`, `section-portfolio`, `section-budgets`, `section-cashflow`, `section-documents`). Branding: logo tile + **Wealth Curator** + footer institutional line.

2. **`MainHeader`** — Top of the main column:
   - Optional sidebar toggle when wired (narrow layouts).
   - **Search** (leading magnifier) with shared query state with the transactions block.
   - **Theme toggle** (sun/moon).
   - **Profile**: avatar initials + tier line (**PRIVATE CLIENT** style text from `planTier`); **notification and settings icons were removed** per latest UX.
   - **Tabs**: Overview, Portfolio, Insights, Planning — same navigation model as sidebar scroll targets.

3. **`ScrollView`** — Main document scroll; sections are stacked vertically with `nativeID` for in-page navigation.

4. **Profile overlay** — Right sheet with **`ProfileSection`** when “profile” is opened from sidebar or avatar.

## 4. Major feature areas (by section)

### Overview (`section-overview`)

- **Monthly overview** title + fiscal period (current month/year).
- **`BudgetVelocityHero`** — Large card: spent vs limit, progress bar, surplus + savings efficiency side stats, **+ Adjust limits** (scrolls to budgets).
- **`SummaryCards`** — Net worth, monthly spending, savings rate with **Lucide** icons.

### Insights (`section-insights`)

Replaced a simple card grid with **`PortfolioInsights`**:

- **Wealth intelligence** kicker + **Portfolio Insights** title.
- **Active signal** card: rebalance-style badge, headline/body from **`getPortfolioInsightsModel`** + **`buildInsights`**, confidence gauge, **Review Strategy** / **Dismiss**.
- **Market sentiment** card: semi-circular gauge, score, fixed narrative rows (e.g. equities / fixed income / volatility).
- **Portfolio performance**: formatted net worth, delta %, **`InsightsPerformanceChart`** (area chart, **1M / 3M / 1Y / ALL** toggles).
- **Sector allocation** from aggregated **holdings**; **Top mover** + **Risk** pills.
- **Cash flow intelligence**: three cards (surplus, recurring audit, tax-loss copy) informed by **spending** + **subscriptions**.

### Portfolio (`section-portfolio`)

- **`PortfolioSection`** — Table of symbols, names, sectors, weights, drift.

### Budgets (`section-budgets`)

- **`SpendingBars`** — “Category allocation” header, bars + **lazy** `SpendingRecharts` donut.

### Cashflow (`section-cashflow`)

- **`AlertsSection`** — List of alerts with optional CTA.
- **`TransactionsList`** — Virtualized rows, **second search field** synced with header search, category chips, empty state when filters match nothing.

### Documents (`section-documents`)

- **`DocumentsSection`** — List of statements / tax / legal items with status.

## 5. Data & logic

### Mock API (`mockApi.js`, `mockData.js`)

- **`fetchDashboardMock`** simulates latency and returns **`MOCK_DASHBOARD`** (or empty/error shapes when `?empty=1` / `?fail=1`).
- Transactions include a rotating **`ticker`** field so search placeholder copy matches data.
- Data powers summaries, charts, insights, and filters.

### Insights engines (`insights.js`)

- **`buildInsights(data)`** — Returns an array of insight objects (title, body, badge, id) used for narratives and (where relevant) portfolio insights copy.
- **`getPortfolioInsightsModel(data, insightsArr)`** — Builds the structured model for **`PortfolioInsights`**: tech delta headline, sector rollups, top mover, sentiment heuristics, etc.

### Search & filters (`DashboardScreen.jsx`)

- **`useDebounce`** on search query; **empty string clears immediately** (no delayed “stuck filter”).
- **`filteredTransactions`** matches combined text (merchant, category, id, ticker) or **digits-only** against rounded amounts.
- **`useEffect`** resets virtual list scroll top when filters change so results are not “hidden” above the fold.

## 6. Custom hooks (`src/hooks/`)

| Hook | Role |
|------|------|
| **`useFetch`** | Async state + `AbortSignal` + `refetch`; used for dashboard JSON. |
| **`useAnalytics`** | `dataLayer` / optional `gtag`; event names from **`analytics/events.js`**. |
| **`useDebounce`** | Search debounce with fast clear on empty input. |
| **`useLocalStorage`** | JSON persistence (e.g. theme key `wc-theme`). |

## 8. Performance techniques

- **Route-level** lazy load of `DashboardScreen`.
- **Lazy** Recharts bundles for charts.
- **`manualChunks`** in Vite: `vendor`, `router`, `virtual`.
- **Virtualization** for long transaction lists.
- **Memo** on heavy list/section components where props are stable.

## 11. Known trade-offs (intentional)

| Topic | Note |
|--------|------|
| No real backend | Mock-only; swap `createJsonFetcher` + env URLs when ready. |
| “AI” insights | Rule-based copy, not a hosted LLM. |
| RN Web + DOM | Charts and virtualizer use DOM nodes under RN `View` for performance. |
| Large dashboard chunk | One feature-heavy route; acceptable for a single-page demo. |
